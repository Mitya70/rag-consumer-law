# Данные

| Файл | Содержание |
|---|---|
| `corpus.jsonl` | корпус: одна строка = одна статья (идентификатор `zpp:18`, `gk:497`, название, глава, текст, разбивка на пункты) |
| `corpus_meta.json` | дата загрузки, версии страниц источника, число статей и символов |
| `texts/zpp.txt`, `texts/gk.txt` | те же тексты в читаемом виде |
| `eval_set.csv` | оценочный набор вопросов (см. ниже) |

## Источник корпуса

Тексты взяты из Викитеки (ru.wikisource.org) скриптом `src/fetch_corpus.py`:

- Закон РФ от 07.02.1992 № 2300-1 «О защите прав потребителей» (страница «Закон РФ от 07.02.1992 № 2300-I»): 51 статья с содержанием, утратившие силу статьи без текста пропущены;
- Гражданский кодекс РФ, часть вторая, глава 30, § 2 «Розничная купля-продажа», статьи 492-505 (страница «Гражданский кодекс РФ/Глава 30»): 14 статей.

Дата загрузки и номера версий страниц Викитеки записаны в `corpus_meta.json`. Страница закона в Викитеке последний раз правилась 2023-12-30, поэтому **текст может не совпадать с действующей редакцией**: проект учебный и не является юридической консультацией. Для практических вопросов используйте официальный портал правовой информации (publication.pravo.gov.ru).

Нормативные акты не являются объектами авторского права (ст. 1259 ГК РФ), поэтому тексты можно хранить в репозитории. Постановление Правительства РФ № 2463 (Правила продажи товаров) в Викитеке не найдено и в корпус не вошло.

## Оценочный набор `eval_set.csv`

| Колонка | Смысл |
|---|---|
| `qid` | номер вопроса |
| `question` | вопрос потребителя на русском языке |
| `gold_answer` | эталонный ответ (пусто для вопросов без ответа в корпусе) |
| `gold_article_id` | статья, в которой находится ответ |
| `evidence` | дословные цитаты из статьи, на которых основан эталон |
| `qtype` | тип вопроса: срок, право потребителя, исключение или ограничение, ответственность или санкция, расчёт или размер, вне корпуса |
| `answerable` | `True`, если ответ есть в корпусе |
| `source` | `llm_draft_judge_model` (черновик модели, отфильтрованный программно) или `manual_out_of_scope` |
| `verified_by_human` | проверен ли вопрос человеком; **по умолчанию `False` для всех строк**, см. `review/review_sample.md` |

Как построен набор: `src/build_eval_set.py` просит модель-оценщик составить по тексту статьи вопрос, ответ и цитаты; затем отбрасываются вопросы, ссылающиеся на номер статьи или закон, вопросы с цитатой, которой нет в статье дословно, и лексические дубликаты. Вопросы без ответа в корпусе (проверка отказа от ответа) написаны вручную; для каждого проверено, что характерных слов (например, «ОСАГО», «НДС») в корпусе нет.
